Analytics

Reads your GoatCounter data directly from your browser. Nothing is sent anywhere else.

Create a token at chargeandchew.goatcounter.com → Settings → API tokens, with “Read statistics” permission. It is stored only in this browser’s local storage and sent only to GoatCounter. This page is noindex and not linked from the site — but it is a public URL, so the token is what protects your data, not the address.
